The webpage consists of the following major sections:

The header contains the LearnHub logo, navigation links, and a Get Started button.

The features section contains four cards:

1. Learning Resources
2. Practice & Quizzes
3. Track Progress

The about section explains the purpose of the platform and displays learning statistics.

The footer contains the platform name, description, navigation links, and copyright information.

## 7. Responsive Design

Responsive design was implemented using CSS media queries.

Three major responsive breakpoints were included:

### Desktop

The desktop version uses multi-column layouts and provides a spacious presentation.

### Tablet

At medium screen sizes, the layout changes from multiple columns to fewer columns to maintain readability.

### Mobile

On mobile devices:

* Navigation links are hidden.
* Hero content becomes vertically stacked.
* Feature cards become single-column.
* Buttons expand to available width.
* About content becomes vertically arranged.
* Footer elements are stacked.

This allows the webpage to work effectively across different screen sizes.

## 9. Challenges Encountered

During development, several layout-related challenges were considered.

### Challenge 1: Maintaining Responsive Layout

A desktop layout can become difficult to read on smaller screens.

**Solution:** CSS Grid and media queries were used to change the number of columns depending on screen size.

### Challenge 2: Maintaining Consistent Spacing

Different sections require different amounts of spacing.

**Solution:** Consistent container widths, padding, margins, and spacing values were used throughout the page.

### Challenge 3: Mobile Layout

The desktop navigation and multi-column content do not fit well on small screens.

**Solution:** Media queries were implemented to stack content vertically and simplify the navigation.

### Challenge 4: Visual Hierarchy

Important information needed to stand out from supporting content.

**Solution:** Different font sizes, font weights, spacing, and blue accent colors were used to create a clear visual hierarchy.
